# Resource packs and load order (0.3.1)

`options.txt` lists packs lowest priority first; a later pack overrides an earlier one. `build.py` writes this order
(`resourcePacks:` line) and keeps any extra pack the player enabled **above** ours.

| # | Pack | Source | Why it is here |
|---|---|---|---|
| 1 | vanilla, mod_resources | built in | base |
| 2 | Vocal Villagers | Modrinth `vvi` 1.5 | villager voices |
| 3 | Fire Rekindled | Modrinth `fire-rekindled` 0.21 | fire textures |
| 4 | Animated Hearts | Modrinth `animated-hearts` 1.0.0 | HUD hearts |
| 5 | Fresh Animations | Modrinth `fresh-animations` 1.11.2 | base mob animations (needs EMF + ETF, both installed) |
| 6 | FA: Details 2.4.0 | Modrinth `fresh-animations-details` | extra detail on vanilla mobs (replaces the old All-Extensions bundle) |
| 7 | FA: Emissive 1.7.0 | Modrinth `fresh-animations-emissive` | glowing eyes/parts (ETF emissive) |
| 8 | FA: Quivers 2.3.0 | Modrinth `fresh-animations-quivers` | quivers on skeletons and players |
| 9 | Fluid & Foolish | Modrinth `fluid-foolish` | fluids |
| 10 | **Horizon 16x** | `resourcepacks/Horizon-16x.zip` (this repo) | Quest Book item art, pack icon, reward-cue sound table |

Why not the All-Extensions bundle any more: 0.3.0 shipped the bundle, which contains Details, Emissive, Quivers **and**
Objects, Spiders, Creepers and Classic Horses. 0.3.1 splits it so each add-on is a decision:

| Add-on | State | Reason |
|---|---|---|
| Details, Emissive, Quivers | on | Vanilla-mob only; no installed mod re-models those mobs. |
| Spiders | held back | Spider Overhaul adds 14 spider entity types with their own models; FA Spiders would only re-animate vanilla spiders, so the two would look different side by side. Not checked visually. |
| Objects | held back | Animates vanilla blocks via EMF; interplay with Lootr/Sophisticated Storage/Create block models not checked. |
| Creepers, Classic Horses | held back | Not checked in game. |
| Animals | n/a | The base pack already covers vanilla animals; no installed mod replaces vanilla animal models. |
| Player (FA Player Extension) | off | Punchy Moves reports it incompatible (tested in 0.3.0). Player animation is owned by Punchy Moves + Better Combat. |

## Horizon 16x

Built by `python scripts/gen_resourcepack.py` (deterministic; all art drawn by the script, no third-party assets):

- `assets/heracles/textures/item/quest_book.png` - 16x16 Quest Book (the item the book quest and first login give).
- `assets/horizon/sounds.json` - reward cues. Each cue is a Horizon sound event mapped to **vanilla** sound events, so
  no audio files are shipped:

  | Cue | Played for |
  |---|---|
  | `horizon:cue.item_found` | first find of a Horizon item |
  | `horizon:cue.rare_loot` | rare find tier, relic received |
  | `horizon:cue.mythic` | top tier find (Starforged Heart) |
  | `horizon:cue.trophy` | a Legend credited (trophy placed) |
  | `horizon:cue.legend_slain` | the boss-kill sting that goes with it |
  | `horizon:cue.quest_claim` | claiming a quest in the quest popup |

  The same table is written to `kubejs/assets/horizon/sounds.json`, so the cues exist even if the pack is disabled.
  To change a cue, edit `CUES` in `scripts/gen_resourcepack.py` or override `assets/horizon/sounds.json` in your own pack.

Not in the pack: GUI sprites for the quest screen. The popup is drawn in code, and re-skinning Heracles' own sprites
would mean copying its artwork, which this pack avoids. Item and trophy textures are generated by `gen_assets.py` into
`kubejs/assets`; whether a resource pack can override those has not been tested, so this pack does not try.

## 0.6: Fresh Compats (optional)

Fresh Compats v1.6 (MIT, `EHQK5l1g`) adds Fresh Animations support for Quark (bee variants and other entities) and
Supplementaries. The 0.5 exclusion ("Quark and Supplementaries are absent") was stale: both are in the pack. It ships in
`resourcepacks/` but is **not enabled** (`enabled_by_default: false` in the roster; `build.py set_resourcepacks` leaves it
out of `options.txt`), because no in-game check of its Quark bee variants against Dynamic Trees, EMF/ETF 3.3.12/7.2.7 and the
existing FA add-ons was possible. To enable it: Options > Resource Packs, move it above Fresh Animations (and its add-ons),
below Horizon-16x. FA Player Extension stays excluded (Punchy Moves conflict).

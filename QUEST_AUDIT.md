# Quest audit (0.5)

214 quests, 16 chapters (was 143 / 13). Original 143 keep their ids, so existing saves keep progress.

New chapters (generated by `scripts/quest_campaign.py`, merged by `scripts/gen_quests.py`):
- **0 - The Horizon Campaign**: 33 quests, five acts, branching optional hunts (Frostmaw, Wroughtnaut, Dead King, Slider, Sun Spirit, Wither, Ignis).
- **14 - Bounties and Hunts**: 8 skill bounties (vanilla advancements) and 8 realm boss bounties (retroactive first-kill advancements).
- **15 - Discoveries and Relics**: structure-family milestones, Master Cartographer (all 13 families), relic trio, five-dimension walker.

Validation done: `audit_quests.py` 0 problems (titles, prerequisites, cycles, objective lines, no reward-shortcut to item tasks, no relic rewards);
every non-vanilla id checked against the jar index at generation; vanilla item ids reviewed by hand; headless dedicated server
boots with the book and datapacks and logs no quest errors (`Done`, only the known `wares:`/Incendium/Tectonic noise).

Known issues / unverified: node layout and popups not inspected in the client; the default layout stacks same-depth side quests in rows;
vanilla advancement ids (adventure/*, story/*) come from the 1.21.1 advancement set, not from the jar index;
Monster Hunter (`kill_all_mobs`) is a very long task by design; dependency semantics assumed AND (Heracles default).
